# 🏦 Bank Management System

A simple Bank Management System developed using **Java** and **MySQL**. This application allows users to perform basic banking operations such as account creation, deposits, withdrawals, balance inquiry, and fund transfers.

## 🚀 Features

- Create a New Bank Account
- Customer Login
- Deposit Money
- Withdraw Money
- Transfer Funds
- Balance Inquiry
- View Account Details
- MySQL Database Integration

## 🛠️ Technologies Used

- Java
- JDBC
- MySQL
- Object-Oriented Programming (OOP)

## 📂 Project Structure

```
Bank-Management-System/
│── src/

```

## ⚙️ Prerequisites

- Java JDK 8 or above
- MySQL Server
- MySQL Connector (JDBC)
- IDE (Eclipse / IntelliJ IDEA / VS Code)

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/rakesh0095/Bank-Management-System.git
```

2. Open the project in your preferred Java IDE.

3. Create the MySQL database.

4. Update the database credentials in the source code.

5. Run the main Java file.
